MUGIC MOTION — Windows Installation

Version 2.1.0 · Windows 10 / 11, 64-bit

The Windows download — MUGIC-MOTION-2.1.0-windows-x64.zip — contains two things:

File What it is
MUGIC MOTION Plugin.vst3 The VST3 plug-in — use this in Ableton Live, Reaper, Cubase, FL Studio, Bitwig
MUGIC MOTION Plugin.exe The standalone app — runs on its own, no DAW required

There is no AU (Audio Unit) version on Windows. Audio Units are a macOS-only format. On Windows, VST3 is the equivalent. (Logic Pro is macOS-only, so nothing is missing.)

1. Install the VST3 plug-in

Copy the whole MUGIC MOTION Plugin.vst3 folder into the system VST3 folder:

C:\Program Files\Common Files\VST3

⚠️ MUGIC MOTION Plugin.vst3 looks like a file but is actually a folder. Copy the entire folder — not just the file inside it. If you only copy the inner file, your DAW will not find the plug-in.

You'll need administrator rights to write to Program Files. If Windows blocks it, right-click Explorer → Run as administrator, or copy to your user folder instead:

%LOCALAPPDATA%\Programs\Common\VST3

Then restart your DAW and rescan plug-ins if needed:

  • Ableton Live — Options → Preferences → Plug-Ins → Rescan
  • Reaper — Options → Preferences → Plug-ins → VST → Re-scan
  • Cubase — Studio → VST Plug-in Manager → Update Plugin Information

MUGIC MOTION is an instrument, not an audio effect. It appears under your DAW's instruments (VSTi) — in Ableton Live, Instruments → MUGIC MOTION Plugin — never under audio effects. Drag it onto a MIDI track.

2. Or just run the standalone app

Double-click MUGIC MOTION Plugin.exe. No installation needed. You can put it anywhere (Desktop is fine).

"Windows protected your PC" — this is expected

This build is not code-signed, so Microsoft SmartScreen will warn you on first launch. It is not a virus warning — it means we haven't bought a Windows code-signing certificate yet (separate from our Apple one).

To run it anyway:

  1. Click More info
  2. Click Run anyway

You should only have to do this once.

If the window is blank: install WebView2

The MUGIC MOTION interface is drawn with Microsoft Edge WebView2. This ships with Windows 11 and most updated Windows 10 machines — but if the plug-in or app opens to an empty / white window, install the free runtime:

Microsoft Edge WebView2 Runtime → https://developer.microsoft.com/microsoft-edge/webview2/ (choose the Evergreen Standalone Installer, x64)

Then restart the app or DAW.

Connecting your MUGIC device

  1. Power on the MUGIC and make sure it's on the same Wi-Fi network as the PC.
  2. In MUGIC MOTION, open the Device tab: - UDP port — default 4000 - OSC prefix — default /mugicdata These must match what the device is configured to send.
  3. When data arrives, the dot next to the device's name turns green and the "not connected" note disappears.

If nothing moves, the most common causes are: the device is on a different network, another app already holds the port, or the Prefix doesn't match the device's configured data prefix. As a quick test, clear the Prefix field — an empty prefix accepts data on any address.

Windows Firewall

The first time it runs, Windows may ask whether to allow network access. Allow it — the device streams over UDP, and blocking it means no data. If you dismissed that prompt, re-enable it under Windows Security → Firewall & network protection → Allow an app through firewall.

Calibrating

The plug-in opens on the Calibrate tab. Hold MUGIC in your resting position and click Reset Orientation. Then click Calibrate YAW (or PITCH, ROLL) and keep moving that axis back and forth through its full range until the countdown ends. The furthest points you reach become its range: 0 and 127 on MIDI. Calibration length (5 s by default) sets how long each one lasts.

Don't just hold a pose — the whole window is recorded, so a still device produces no usable range.

Sending MIDI

The Map tab has one row per thing MUGIC measures: YAW, PITCH and ROLL angles, ENERGY and JOLT, and — under the arrow next to each axis — that axis's speed and steadiness (new in 2.0). In Sends as, type a CC number or pick a named controller or pitch bend; none mutes that row. Continuous tracks the motion; Switch is on while above "Switch at" and off below; Toggle flips on/off each time the motion rises past it. The sliders button on a row opens its settings: MIDI Min / Max, channel, and its calibration (Speed, Energy, Jolt). Click LEARN on a row and the plug-in sends only that row, so your DAW's MIDI-learn latches the right control.

A 14 button sits next to any CC from 0 to 31. Turn it on to send that CC at high resolution — 16,384 steps instead of 128 — as the standard 14-bit pair (CC 14 + CC 46, CC 1 + CC 33, …); or just type a + after the number, e.g. 14+. Use it only when the synth or DAW receiving it understands 14-bit CC (set its assignment to 14-bit); anything else sees two unrelated controllers.

Getting the MIDI into Ableton Live. Ableton's MIDI Map mode only listens to MIDI ports, never to MIDI coming out of a plug-in, so for LEARN install a virtual port such as loopMIDI, pick it in Out, and turn on Remote for it in Ableton's MIDI settings. To play an instrument on another track instead, DAW (Host) works: set that track's MIDI From to the MUGIC MOTION track and Monitor to In.

If something goes wrong. Click Clear log on the Device tab (or in the ? help window), make the problem happen again, then click Show log file (or open %APPDATA%\MUGIC MOTION\mugic.log) and send that file with your report. It's plain text: open it in Notepad and delete anything you'd rather not share first. It only holds the plug-in's own actions, and keeps just the most recent part.

Controlling the plug-in from your DAW (new in 1.1.0)

The plug-in's buttons are now also parameters your DAW can see, so you can work them from a MIDI controller or an automation lane instead of reaching for the plug-in window mid-performance. The one most people want: put Reset Orientation on a footswitch or a pad and re-centre without touching the PC.

What's available, for each MUGIC (M1...M12), plus an All version that hits every connected device at once:

Parameter What it does
Reset Orientation Re-centres the device — wherever it's pointing now becomes "straight ahead"
Reset Wrap Clears built-up yaw wrap-around
Reset Range Cal Clears the sweep calibration for that device
MIDI Out Turns that one device's MIDI output on/off — a per-device mute

The three resets are momentary: they fire once when the button goes down, so a controller button that sends on-press / off-release does exactly the right thing, and holding it down won't keep re-firing. MIDI Out is an ordinary on/off switch and stays in step with the MIDI ON/OFF button in the plug-in window, whichever one you change.

Ableton Live — click the plug-in's Configure button so the parameters are listed, press Ctrl+M for MIDI Map Mode, click the parameter, then press your controller button.

Reaper — right-click the parameter in the FX window → Learn, then press your controller button.

Cubase / FL Studio / Bitwig — use the host's usual "learn" on the parameter, or draw it into an automation lane and put a short blip where you want the reset.

SuperCollider (VSTPlugin) — the parameters are addressable by name, e.g. ~fx.set("Reset Orientation (M1)", 1); ~fx.set("Reset Orientation (M1)", 0); Use ~fx.printParams to list them.

Note that the motion values themselves (yaw, pitch, roll, energy, jolt) are not in this list, and that's deliberate — a plug-in parameter is something the DAW sends into the plug-in. Motion still comes out as MIDI, exactly as before; see Sending MIDI above.

Known limitations in this build

  • Not code-signed (SmartScreen warning, above).
  • Yaw left/right may be reversed depending on how the sensor is oriented on your hand or instrument. Pitch and roll are unaffected.
  • Some panel labels can be clipped if the window is small — drag the window larger.
