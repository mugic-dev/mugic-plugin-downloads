MUGIC Bluetooth — macOS

Version 1.0.0 · macOS 11 Big Sur or later · Intel and Apple Silicon

MUGIC Bluetooth receives your MUGIC's motion data over Bluetooth and sends it on, unchanged, as UDP — so the MUGIC MOTION plug-in, Max and Ableton receive it exactly as if the MUGIC streamed over Wi-Fi. There's no Wi-Fi network to set up, and Bluetooth uses less battery.

The download is MUGIC-Bluetooth-1.0.0-universal.pkg.

1. Install

Double-click MUGIC-Bluetooth-1.0.0-universal.pkg and follow the installer. It puts MUGIC Bluetooth in your Applications folder.

The first time it opens, macOS asks whether MUGIC Bluetooth may use Bluetooth: click Allow. If you clicked Don't Allow, the app says so at the top; turn it on in System Settings → Privacy & Security → Bluetooth.

2. Put your MUGIC in BLE mode

MUGIC Bluetooth needs MUGIC firmware 2.2.0 or later. To check or update it, use the MUGIC firmware page.

Press the MUGIC's Mode button until it is in BLE mode (each press moves on: Wi-Fi → BLE → USB). The MUGIC restarts, and its LED shows:

LED Meaning
green, blinking fast BLE mode, waiting for MUGIC Bluetooth
green, blinking slowly sending its data to MUGIC Bluetooth

In BLE mode the MUGIC's Wi-Fi is off. Press Mode again to go back to Wi-Fi.

3. Pick your MUGIC

Each row is one MUGIC:

Column What to set
BLE NAME the MUGIC's Bluetooth name — open the list to see the MUGICs nearby
IP where to send: 127.0.0.1 is this computer
UDP PORT 4000 for the first MUGIC, 4001 for the second, …
STATUS Searching…, Connecting…, then the data rate, e.g. 50 Hz → :4000
BATTERY the MUGIC's battery

Then, in the MUGIC MOTION plug-in (Device tab), Max or Ableton, receive on the same UDP port, just as you would with Wi-Fi. Leave MUGIC Bluetooth open while you play: it only forwards while it's running.

+ Add slot adds a row on the next port. Two rows with the same BLE name both receive that MUGIC (for example to send it to two programs). Menu → Save setup… / Open setup… keeps your rows in a .mugicbluetooth file; the rows you had are also kept from one run to the next.

If something doesn't work

  • Searching… — the MUGIC isn't advertising: it's off, out of range, not in BLE mode, or already connected to something else (for example the MUGIC BLE configurator page — close it).
  • No BLE output — the MUGIC isn't in BLE mode, or its firmware is older than 2.2.0. Update it, then switch it to BLE mode.
  • A message at the top of the window — Bluetooth is off — turn it on in System Settings → Bluetooth.
  • Data rate shows but nothing arrives in your program — the program must listen on the same UDP port as the row, and only one program can listen on a port. Use another row and port for a second program.
  • Bluetooth reaches a few metres, less through bodies and walls; keep the computer near the stage.
