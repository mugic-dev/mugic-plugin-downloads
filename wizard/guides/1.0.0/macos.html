MUGIC Wizard — macOS

Version 1.0.0 · macOS 11 Big Sur or later · Intel and Apple Silicon

MUGIC Wizard sets up your MUGIC over Bluetooth, step by step: it checks the firmware, lets you pick how MUGIC sends its data, fills in your Wi-Fi network for you, and finishes when data actually arrives on this computer.

The download is MUGIC-Wizard-1.0.0-universal.pkg.

1. Install

Double-click MUGIC-Wizard-1.0.0-universal.pkg and follow the installer. It puts MUGIC Wizard in your Applications folder.

The wizard asks for three things the first time it needs them. Each one is optional, but saves you typing:

macOS asks Why If you said no
Bluetooth to talk to your MUGIC the wizard can't work; turn it on in System Settings → Privacy & Security → Bluetooth
Location macOS only shows an app the Wi-Fi network's name if it may use Location. The wizard doesn't use where you are. type the network name yourself, or turn it on in System Settings → Privacy & Security → Location Services
Keychain (your Mac's name and password), when you click Use the password saved on this Mac to read this network's saved Wi-Fi password type the password yourself

For the keychain, Always Allow means the wizard won't ask again for that network; Allow asks next time. The password goes only to your MUGIC: the wizard doesn't keep it.

2. Connect

Turn your MUGIC on, keep it close, and press Power + Mode together, briefly. In Wi-Fi modes MUGIC only turns Bluetooth on when asked, to save battery; its LED blinks while Bluetooth is on. A MUGIC already in Bluetooth mode is always visible and needs no buttons. Pick your MUGIC in the list.

If the firmware is older than 2.3.0, the wizard offers to open the MUGIC firmware page. You can skip it: the wizard still works, with fewer features (it can't list the networks MUGIC sees or say why joining failed).

3. Choose how MUGIC sends its data

Choice When to use it
Wi-Fi: join your network MUGIC joins the same Wi-Fi as this computer. Up to 8 computers.
Wi-Fi: MUGIC's own network Your computer joins a network made by MUGIC. Good on stage, at school or at work. Up to 4 computers.
Bluetooth No Wi-Fi needed. Use MUGIC Bluetooth on this computer to receive it.
USB For troubleshooting, or where wireless can't reach.

The wizard fills in what it can (this computer's network and address), checks each step, and ends on a screen that shows data arriving.

If something doesn't work

  • Your MUGIC doesn't appear — press Power + Mode again (Bluetooth turns off after a minute without a connection), keep it close, and close other apps or web pages connected to it (MUGIC Bluetooth, the BLE configurator).
  • A message about Bluetooth at the top — Bluetooth is off: turn it on in System Settings → Bluetooth.
  • "MUGIC couldn't find" your network — MUGIC only uses 2.4 GHz Wi-Fi. Many routers have a separate 2.4 GHz network name; pick that one.
  • "MUGIC couldn't join" — usually the password. Check it in the Wi-Fi menu (top right of the screen) and try again.
  • MUGIC joined, but no data arrives — school, office and guest networks often block devices from talking to each other. Use MUGIC's own network instead.
  • Main Menu → Show log file opens the wizard's log (~/Library/Logs/MUGIC MOTION/mugic-wizard.log); send it to us with your question. Clear log empties it before you try again.
